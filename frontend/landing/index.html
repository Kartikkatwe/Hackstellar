Questions about the engine

Does it need training data?

No. Jev takes the labels with each request, so a new business needs one settings file, not a trained model.

How is one customer counted once?

Each complaint is tied to a customer by sender email, caller number, chat login or a verified order ID with a check digit.

Which languages does it read?

English, Hindi and mixes of both. The similarity model is multilingual and Jev reads Hinglish as written.

What if the live models are down?

The complaint goes through offline stand-ins, and the console labels the result so nobody takes it for a live one.

Does it work beyond groceries?

Yes. Areas, issues, severity and customer groups live in one settings file per business. A telecom pack is next.
