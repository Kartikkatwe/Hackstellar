The gate is one call to Jev, a decision model, with six questions: is it a complaint, which of the seven areas, impact, emotion, money lost, legal or safety risk. A decision model fits because every answer is a choice, not writing: it returns probabilities, so an unsure answer is passed on instead of guessed, and it writes nothing, so it is fast and cheap. The questions come from the business's settings file, so a new business needs no training.
