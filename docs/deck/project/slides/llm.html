Pause before this slide. Then: the usual way to build this is to send every complaint to an LLM and let it decide. It works, but two things go wrong. Click: every complaint waits on the model, at least 1.9 seconds, measured on Claude Haiku 5.5 with a short prompt, so a real everything-prompt is slower. Click: the LLM writes an answer for every single complaint, about 200 tokens each, and output tokens are the expensive ones. Then pause again before the numbers.
