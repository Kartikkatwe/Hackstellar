How Jev works, and who does what. Three workers, by colour. Top row, Jev: a decision model. You give it the complaint and a list of questions with fixed options, and it returns a choice and a probability for each, never free text. It does three jobs. The gate: one call per complaint, six questions, is it a complaint, which area, impact, emotion, money lost, legal risk. Verify: when a match is unsure, is this the same problem as these three, yes or no. Group check: before we create a new problem, is this a known one in new words. Middle row, green, is free and runs on the laptop: reading the channels, finding the customer, matching by meaning, the waiting list, and the ranking. Bottom row, the LLM, Claude Haiku: only where words are needed. Deciding the last unsure few, naming new problems, and merging duplicates. Jev needs no training: the labels come from the business's settings file per request, so a new business only writes that file.
