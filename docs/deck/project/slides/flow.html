The whole flow, top to bottom. Colour shows who does the work: green is free on our machine, blue is Jev, orange is the LLM. 1, intake: four channels become one format and we find the customer; order IDs are checked for typos with a check digit. 2, the gate: Jev answers six questions in one call; praise, spam and questions are removed, 10 percent of the run. 3, similarity match: free, files half of all complaints on its own. 4, verify: only for unsure matches, Jev answers same problem yes or no; another 35 percent filed. 5, decide: the LLM only if still unsure, 1.7 percent. 6, the waiting list: things that match nothing wait until 3 different customers report them, except lost money or safety risk, which is flagged urgent at once. 7, group check: Jev asks if it is a known problem in new words. 8, if not, the LLM names the new problem. After each batch, 9, the LLM removes duplicate problems, and 10, the ranking builds the Top 10 with a written score anyone can check. Every confirmed wording becomes an example, so the system gets cheaper the longer it runs.
