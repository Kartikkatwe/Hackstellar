Before a judge finds them, here are the eight places today’s prototype would break, and the fix for each. The first two are the big ones: one global writer and an in-memory issue list, and SQLite. Both go away with the partitioned design and Postgres. The gate is network-bound at about half a second per call, so we add workers and reuse answers for near-identical texts. Vectors get sparse storage and an index. The ranker moves to running totals. Jev is on the critical path, so we add a degraded mode that sorts by similarity and re-checks when Jev is back. Rate limits are the real unknown, so a load test comes before any throughput claim.
